# How to Use This Book 🧭

A few minutes here will save you hours later.

---

## The Weekly Rhythm

Each module maps to roughly one week of the course:

1. **Before class**: read the module's overview page, then its section pages, then the assigned readings linked in the readings table. The book pages give you the map; the readings are the territory.
2. **In class (M/W)**: lectures, discussion, and activities build on — but don't repeat — the book. If you skip the reading, class will feel like walking into a movie an hour late.
3. **Friday**: reflection discussions, led by your classmates. The module's Reflection Prompt box gives you a ready-made angle if you need one.

## Anatomy of a Module

Every module follows the same pattern:

| Element | What it's for |
|---------|---------------|
| **Overview page** | Learning objectives, big questions, this week's readings, and assignment reminders |
| **Section pages (2–3)** | The actual chapter content: concepts explained, evidence presented, readings put in context |
| **Boxes** | 💡 *Tips* give advice · 📝 *Notes* add context · ⚠️ *Warnings* flag common mistakes · 🔍 *See Also* points to related material |
| **Reflection Prompt** | A starting point for Friday reflections |

## Reading the Readings

Not all readings ask for the same kind of attention, and the readings tables tell you which is which:

- **Core** readings: read carefully, before class. These show up in discussions and assignments.
- **Skim** readings (reports, government documents): read the executive summary and the sections we flag; know what's in the rest.
- **Optional** readings: for when a topic grabs you — and gold mines for paper topics.

## Links, Citations, and Zotero

Every claim in this book links to its source. When a reading is a journal article, the citation is in APA style — the same style you'll use in your papers. Consider adding readings you like to [Zotero](https://research.dom.edu/citationguides/zotero) as you go; by paper time you'll have a reference library already built.

## Dark Mode, Search, and Offline Use

The icons in the top bar let you switch themes and search the whole book. Every page can be downloaded or printed — but the links, obviously, work best online.

:::{tip} The one habit that matters
Come to class having read. Everything else in this course — the discussions, the papers, the grade — gets easier if you do that one thing.
:::
